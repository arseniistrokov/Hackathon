# Образцы кода (фиксированы)

Агент пишет код в стиле и структуре этих файлов. Какие папки применять к блоку — сказано в `docs/references/<ID>/README.md`.

| Папка | Для кого | Что показывает |
|---|---|---|
| `backend_block/` | D1, I1, I2, S1, A1, R1, R2, L1, W1, E1 | раскладка `__init__.py` (порт) / `l0.py` / `l1.py`, откат L1 → L0, тесты на fixture без сети, `fixture_loader.py` для D1 |
| `llm_call/` | L1, W1, S1, E1 | как звать модель: только через `app.blocks.llm.complete_json`, схема ответа — pydantic, внешний текст — данные в `user` |
| `frontend_feature/` | U1, U2 | фича = папка; типы из `src/api/types.ts`; mock ↔ API одним переключателем; цвета только токенами |
| `content_block/` | G1, P1 | как выписывать golden-вопрос, конфликтную пару и страницы навигации; чек-лист |

Общие правила: один файл на модуль; без классов-фабрик и плагинов; библиотеки только скучные (`sqlite3`, `numpy`, `httpx`); ленивый импорт тяжёлых моделей внутри `l1.py`; типы везде; `ruff` чистый.
