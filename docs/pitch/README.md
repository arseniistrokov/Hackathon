## Демо-скрипт (5 минут) — CONTEXT.md §14

1. Вопрос по-румынски (заготовленный) → ответ + карточка цитаты → «открыть документ».
2. Тот же тип вопроса по-русски, документ только RO → ответ по-русски, цитата на румынском.
3. Заготовленный вопрос без ответа → NOT_FOUND: «Корпус: N документов, подтверждающих passages: 0».
4. Заготовленный конфликт (наша ручная пара) → две колонки, обе даты, система не выбирает.
5. Голосом вопрос 1 — с включённым Wi-Fi.
6. (Если работает) Wi-Fi выключен, текстом вопрос 2 → отвечает локально.
7. Слайды 8–9.

Вопрос из зала — только если осталось время. Если модель ошиблась — показать passage: «вот почему gate важен». Резерв — backup-видео.

Пять заготовленных вопросов с ожидаемыми ответами записать в `docs/pitch/demo_questions.md` (вопрос, язык, ожидаемый статус, URL источника) и прогнать на репетиции ×3.
