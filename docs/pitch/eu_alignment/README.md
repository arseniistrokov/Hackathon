# EU Alignment Scorecard — официальные материалы организаторов

Справочные файлы GigaHack 2026, на которые опирается заполнение скоркарда с ментором (см. `docs/pitch/README.md`, слайд «EU alignment»).

- `EU_Alignment_Scorecard_GigaHack2026.xlsx` — официальный пустой шаблон: 21 критерий A1–E5, шкала 0–4, полосы индекса (Read Me / Team Scorecard / Criteria Guide).
- `EU_Frameworks_Supporting_Document.docx` — таблица «критерий → конкретный EU-фреймворк» с точными названиями (GDPR-статьи, AI Act, EDIH, EIC Pathfinder/Transition/Accelerator и т.д.).
- Skill `eu-frameworks-helper` установлен в `.claude/skills/eu-frameworks-helper/` — диалоговый помощник (5 вопросов → таблица релевантных фреймворков), баллы не ставит.

Заполненный черновик ответов команды по этим критериям — отдельно, не в этой папке (принеси `EU_ALIGNMENT.md`, если нужно закоммитить и его).
