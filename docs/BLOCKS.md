## Заменяемость: два уровня у каждого блока
- **L0 — без сети, без моделей, без ключей, на `data/fixture`.** Пишется первым. После того как у всех блоков есть L0, **сквозной путь «вопрос → ответ с дословной цитатой» работает целиком** — и дальше не ломается никогда.
- **L1 — настоящее:** сеть, bge-m3, bge-reranker, ollama/api. Включается переменной в `.env`. Любая ошибка L1 → тихий откат на L0.
- **L2 — если успеем.**

**Блок не сделан или сломался → остаёмся на уровне ниже. Продукт беднее, но демо живо.**
«Зависит от» в таблице = «вызывает порт этого блока». Ждать соседа не нужно: у него с первого часа есть L0 (или гнездо с `NotImplementedError`, которое тест замокает).

## Как блоки не ломают друг друга
1. Блоки общаются только моделями из `app/contracts/models.py`. Менять файл может только Арсений, отдельным PR.
2. У каждого блока — свой список разрешённых путей (`docs/contracts/paths.json`). CI (`scripts/check_paths.py`) отклоняет PR, который тронул чужое.
3. Общие файлы заморожены после C0: `app/config.py`, `app/main.py`, `app/api/router.py`, `pyproject.toml`, `data/fixture/**`.
4. Блок импортирует у соседа только `__init__` (порт), никогда — внутренности. SQL только в D1, вызов модели только в L1.
5. Тесты всех блоков — на одном fixture `data/fixture/` с эталоном `expect.json`.

## Порядок сборки
| Фаза | Что | Критерий выхода |
|---|---|---|
| 0 · до хакатона | C0 каркас, fixture, CI, клон у всех | `uv run pytest -q` зелёный у каждого |
| 1 · сб 09:00–13:00 | **L0 всех блоков ядра:** D1, I2, I1, L1, R1, R2, W1, E1, U1; G1 первые 15 вопросов | `eval.py` печатает цифры на fixture; UI показывает три состояния с моков |
| 2 · сб 13:00–18:00 | I1 L1 на 2–3 сайтах → D1 L1 → первый ответ с цитатой end-to-end **к 15:00**; R1/R2/L1 L1 на ноуте; golden 30; Recall@5 измерен | живой ответ на вопрос по реальному сайту с дословной цитатой |
| 3 · сб 18:00–24:00 | S1, A1, U2; вторая волна сайтов; калибровка порога; CONFLICT на настоящей паре | демо-сценарий из CONTEXT.md §14 проходит целиком |
| 4 · вс 09:00–12:00 | только починка, eval hidden, P1 | **12:00 код заморожен** |

**Режем в таком порядке, если горим:** S1 L1 (остаётся ручная пара) → R1 bge-m3 (остаётся hash + FTS) → U2 → вторая волна сайтов → перевод ru→ro (остаётся FTS по ru-страницам + вектор).
**Неприкосновенно:** D1, I1, R2, W1, E1, U1 — без них нет ни цитаты, ни NOT_FOUND, ни цифры.
